📝 To-Do List Web Application

A simple and interactive To-Do List application built using HTML, CSS, and JavaScript. This project helps users organize daily tasks by allowing them to add, complete, and delete tasks. The application also uses Local Storage to save tasks, ensuring that data remains available even after refreshing the browser.

🚀 Features
Add new tasks easily
Mark tasks as completed
Delete tasks when no longer needed
Stores tasks using Local Storage
Responsive and user-friendly interface
Lightweight and fast performance

📖 How It Works
Enter a task in the input field.
Click the Add button to add the task to the list.
Click on a task to mark it as completed.
Click the Delete button to remove a task.
All tasks are automatically saved in the browser's Local Storage.
▶️ How to Run the Project
Using VS Code
Download or clone the repository.
Open the project folder in Visual Studio Code.
Install the Live Server extension.
Open index.html.
Right-click and select Open with Live Server.

The application will launch in your default web browser.

GitHub Pages Deployment
Push the project to GitHub.
Open the repository.
Go to Settings → Pages.
Select:
Branch: main
Folder: / (root)
Click Save.

GitHub will generate a live URL for the application.
